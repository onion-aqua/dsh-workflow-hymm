# DSH Visual Workflow 0.17.3

面向 **DeepSeek Harness 0.2.1-rc.3** 的独立插件。使用当前版本的 Cordis、Client Slots、Typert、Storage Domain、Session Controller、Agent 和原生事件 API，不修改 Harness 本体。

## 界面与操作

- 原生聊天左侧目录默认按工作流名称显示主线、分支及规划对话；名称随工作流重命名同步更新，同名工作流按 ID 独立。分组仅改变显示，不更改工作目录、原生 Workspace 或 Session 上下文。来源及共享对话保持原生分类，其余显示在「其他对话」。可搜索、折叠、打开画布、置顶及归档；顶部「原生目录」恢复原生全部功能，左侧「更多 → 按工作流分组」重新开启。删除工作流并保留的会话回到原生分类。

- 多功能节点未聚焦时可从整卡拖动；第一次单击只聚焦，之后才能操作标题、文件、终端和内嵌网页。聚焦后仍可拖动标题栏，点击画布空白、普通节点或另一多功能节点会切换焦点。失焦保留原生资源和终端进程，仅暂停输入交互。

- 删除工作流自动取消等待队列、停止原生 Agent / 子智能体和规划，完成持久化后移除；停止失败则保留并说明原因。原生历史是否同时归档仍由用户单独选择。
- 点击顶部「运行所选」后切换为「暂停所有」，选区改变后恢复运行按钮。暂停会停止当前工作流所有分支的运行和排队任务。
- 在全局、节点或规划模型列表中右键目标模型，弹出原生思考档位滑条：普通档蓝色、最高档紫色流光粒子。偏好保存于当前工作流，右键调整不切换模型；已提交执行保留原档位。

- 权限菜单使用原生聊天的标准文字与盾牌图标：仅可查看、工作区内修改、完全权限、自动审查 EXP；只显示当前 DSH 实际注册的选项，自定义预设保留名称。
- 删除工作流后单独询问是否一并归档它创建的原生历史对话，默认保留。当前 rc.3 公开 API 仅支持从原生列表归档移除，历史文件保留；导入来源、共享历史及活动会话受到保护。归档前显示可处理数量，确认时重新检查归属和活动状态，部分失败单独反馈，未知结果不自动重试。

- 左侧加号展开两个平行的「任务节点 / 多功能节点」按钮，从加号后方滑出并在右侧排列；再次点击、Escape 或点击外部收起。窄窗口自动改为纵向排列，减少动画偏好下直接显示。画布空白处右键也可在鼠标位置添加两种节点。
- 多功能节点沿用任务节点的外置标题栏、灰阶卡片、圆角与蓝色选中边框。标题栏提供宽拖动区域，移动和缩放持久化，正文仍支持文件、终端、浏览器操作。

- 右上角上下文容量圈读取当前焦点节点或当前分支的原生 Session 投影，显示当前占用 / 模型容量；规划面板使用独立规划会话。没有有效容量时显示“—”，不会用累计计费 token 代替上下文。详情提供原生自动压缩状态、摘要模型、上次压缩与预算配置诊断。
- 节点和规划输入框支持 `/` 菜单。`/compact` 对当前可写、空闲的工作流会话执行原生维护命令，不新建任务或伪造 Execution；运行中、队列待执行、待回答、权限审批和来源会话都不能压缩。`/skills`（也支持 `/skill`）搜索当前真实技能目录，选择后插入 `/<技能名>`，实际运行时由原生 Agent pre-step 加载技能正文。菜单支持键盘导航、中文输入法和长度校验。
- 手动压缩结果保存操作引用，原始摘要仍在 DSH Session。结果不确定时不自动重试。后继和分支能继承经过完整事务校验的压缩检查点，保留任务原始完成边界并防止伪造摘要混入上下文。

- 执行过程窗口优先在节点下方的执行入口下方出现，标题栏可拖动；图钉将面板固定到当前工作流画布坐标，平移和缩放时随画布一起移动，移出屏幕后不会被夹在边缘。固定瞬间保留字体与排版，取消固定保留当前显示位置；执行过程窗口外部右上角图钉可固定当前查看的执行记录，多个固定窗口分别跟随各自 Execution 更新，点击空白不再关闭固定窗口。
- 节点显示 Host 分配的稳定 `#编号`，排序、拖动、隐藏与撤销不会重新编号。原生对话采用“工作流名 · #编号 任务摘要”，分支采用“从 #来源编号 来源摘要 开始分支 · 目标摘要”；设置可整理已存在的插件会话。冷会话不会为整理名称主动恢复 Agent，延后至自然打开处理，原始导入 Session 不改名。
- 顶部模型选择左侧提供原生访问模式入口；仅展示当前 rc.3 已注册的选项。选择影响之后明确点击运行的任务，已执行任务不被升级权限，不改 DSH 全局默认。工具审批使用独立蓝色浮层，仅允许一次或拒绝，不超时自动授权。原生 owned 子 Agent 保留 `approval=never`，自动审查模式使用普通 Session 以保留原生审批语义。
- 工作流设置可关联真实原生工作区目录（建立 Session 后固定）；同目录不会虚构为多个工作区。声音提醒可分别控制完成、失败、提问和审批，使用浏览器用户交互解锁的本地合成短音，不调用外部音频服务。默认关闭。
- 提问超时继续为默认关闭的可选设置（15–3600 秒），只有每道题存在明确标注的唯一推荐选项时才自动回答；多选可使用明确标注的推荐项，缺少或歧义继续等待。不根据选项顺序推断“最优”，不额外请求模型。浮层显示倒计时；用户开始回答会暂停本题自动继续，也可点击暂停。
- 多功能节点独立保存布局，不是任务，不允许连线。节点内提供原生工作区目录/文件/图片只读预览、真实 PTY 终端和 HTTP/HTTPS 网页浏览；终端显式启动，切换画布和刷新恢复同一终端引用，移除面板不终止进程，显式结束才关闭。网页受站点内嵌策略限制；已注册的原生工具可按公开入口打开，未公开可复用正文的第三方工具不能伪装为可内嵌。
- 规划、详情、设置侧栏有淡入淡出，菜单与布局使用短过渡，拖动和缩放保持即时响应。新节点淡入，移除节点显示短碎片淡出（真实图形状态立即更新）；减少动画偏好下关闭。左下角半透明快捷键入口可悬停或键盘聚焦展开；顶部按钮随窗口宽度换行并保持分组。
- Agent 通过原生 `ask_user_question` 提问时，任务节点显示“等待回答”和蓝色虚线呼吸边框，并在附近空位自动展开独立问题浮层。支持单选、多选、自定义回答与明确跳过；收起后可从节点入口或右上角待回答计数重新展开。面板不改变节点尺寸、坐标或连线，减少动画偏好下使用静态边框。
- 问答使用 rc.3 `user-questions/request` 和 `userQuestions.answer`，同时覆盖直接工具与 `run_code` PTC 转发。超时后保留原生继续执行状态，仍可在没有后续任务介入时补充回答；原生支持恢复的待答问题可在重启后读取。旧问题不能向新任务或其他 Session 投递，回答续轮沿用原节点模型，后继任务等待完整续轮结束。原始问题和回答保留在原生 Session，不另存到 Workflow JSON。
- rc.3 原生 owned 子智能体禁止直接向用户提问；插件保留这一限制，不会把子智能体的问题冒充父会话提问。旧版 legacy 实时等待不具备持久恢复能力，重启后不能重建已失效的等待；无法唯一识别的问题回退原生界面。
- 默认进入全屏深色点阵画布，显示原生目录中的全部会话根节点。使用中性近黑画布、18px 圆角深灰卡片、白色圆形新增按钮与胶囊视图切换；规划、模型/工作流选择器、右键菜单、分组、执行轨迹和大编辑器统一灰色层级、轻边线及圆角；蓝色保留给选中与焦点，运行光带沿新圆角贴合；窄窗口顶部操作自动分行。会话内容只读，坐标和尺寸单独保存。
- 顶部支持画布/列表、工作流选择、新建和「原生聊天」切换，原生界面提供「画布」返回按钮。
- 左上角使用深色自定义工作流菜单，蓝色标识当前选择。每个工作流旁的删除按钮通过确认后归档画布及执行引用，原生 Session 与对话历史保留；运行、等待或结果未确认时不能删除。左侧悬浮工具条：创建任务、自动排列、适应画布、计划和设置；规划面板采用聊天历史与底部输入框布局。
- 节点连线采用平滑贝塞尔弧线，拖拽连线时使用相同的曲线预览；正向和反向均直接连接，允许从节点背后穿过，不再为避开卡片大幅绕行；选中连线时也保持在节点下层。端口对齐卡片正文中线，拖动、缩放节点后实时跟随。键盘选中连线后可用 Delete 删除，Esc 取消选择。
- 鼠标靠近连接点约 24 屏幕像素时，圆点轻微向鼠标吸附并高亮；移开后平滑回位。缩放后保持同样的感应范围，支持从靠近位置拖出连线和右键断开；悬停不会移动节点、改变连线锚点或产生布局保存。
- 名称直接显示在节点左上角，单击名称修改；正文不再重复大标题。单击任务正文显示底部悬浮输入框，可直接编辑说明、上传附件、选择当前节点模型并运行；Enter 运行、Shift+Enter 换行，输入法确认不触发运行。切换节点、关闭或点击空白时保存草稿，不改变节点位置；多选和拖动不弹出输入框，原生会话来源保持只读。双击正文打开大型文本编辑框，默认提供可视化富文本，工具栏直接应用粗体、斜体、标题、列表、代码和链接样式；支持切换 Markdown 源码、撤销/重做、字体缩放和最大化，保存或 Ctrl+Enter 提交，取消或 Esc 放弃草稿。来源和正在运行的任务只读查看。
- 左键在画布空白处拖出选择框，选框碰到节点任何部分即可选中；Shift/Ctrl 支持追加选择。中键、右键或空格加左键拖动画布。组合拖动会保存所有选中节点的位置；节点与组使用 4px 启动阈值抑制误拖，按帧更新，释放时保留完整指针位移。右上角「运行所选」一次提交一个或多个任务。其左侧选择工作流模型，节点右下方的独立胶囊气泡默认跟随全局，也可选择独立模型；模型选择不占用卡片正文空间，折叠时隐藏，执行过程入口与其错行避免重叠；修改节点模型会形成新任务版本。全局、节点与规划模型统一采用深色菜单、蓝色选中行及勾选，支持键盘与越界调整。模型列表来自原生 DSH，刷新按钮可在原生配置变更后重新加载。左侧不再显示“全部对话”按钮，仍可从左上角工作流选择器进入会话目录。
- 在节点或画布上点击鼠标右键打开菜单；节点顶部原「…」改为直接折叠/展开按钮。空白右键提供新增节点，节点菜单支持上移一层、下移一层、置顶、置底、重置图层、创建副本、复制/粘贴、重命名和删除草稿，任务详情仍可从菜单打开。
- 右上角“子智能体”提供开启、关闭、自动决定，默认关闭并按工作流保存。开启将已点击且依赖就绪的任务交给原生子智能体；自动决定仅在主路径忙且任务互不依赖时委派；关闭沿用既有 Session 调度。每工作流最多 3 个活跃子智能体，不会跳过前置依赖或运行未点击任务。切换策略不终止活跃任务，但会撤销等待中的旧授权。
- 原生子智能体通过 rc.3 fork provider 启动，使用插件私有协调会话和独立子 Session，固定各节点模型与附件。关闭模式后可从已完成子会话继续普通执行。执行过程从子 Session 原生事件恢复；响应丢失或重启时不自动重发不确定请求。子智能体共享工作目录；需要先后读写同一文件的任务应明确连线，自动决定按依赖图判断。独立会话的多父历史合流保持已有约束。
- 规划直接分解用户要完成的结果，通常只保留 1–5 个必要执行步骤，标题和说明使用用户语言。查询任务优先规划查询和汇总；只有明确要求开发软件时才规划实现、测试和文档。先后要求通过依赖表达，城市名单等关键歧义需确认。1–100 是结构容量，不是默认拆分数量。
- 接受计划时按依赖从左到右分层，同层分支分行，按实际尺寸预留模型气泡空间，并避开既有节点；只布局新增节点。自动排列使用同一套依赖布局。
- 规划结果省略 `dependsOn` 时显示依赖待确认标记，不猜测任务先后顺序；点击“确认依赖并添加所选”后仅创建草案，需要顺序执行的任务可在画布连线。旧版本同类失败结果可从已完成的原生 Session 恢复，不重新请求模型。非法依赖类型、未知任务和循环仍会拒绝。
- 在输入或输出连接点上右键可一次断开该端口全部对应连线，保留节点并支持一步撤销；运行、等待或结果未核对的目标任务需先停止或核对。
- 多选后使用悬浮工具条打组或选择宫格、水平、垂直布局。点击组名选中成员，双击重命名，拖动组标签或边框整体移动；组名及边框右键打开整组菜单，支持图层、复制/剪切/副本、粘贴、重命名、布局、解组与移除；整组图层操作一次撤销。解组只移除分组关系。会话根画布同样支持，所有布局按真实节点尺寸避免重叠。
- 画布 Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做、Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+X 剪切；右键菜单使用同一操作。页面内剪贴板保留选中任务的内部依赖、相对位置、尺寸与分组，同一工作流内保留附件引用。副本均为全新 Draft，不带执行、Session、授权。带附件任务跨工作流粘贴需重新上传；剪切和删除只从画布移走任务，保留执行与分支历史；同一工作流粘贴恢复原节点身份，跨工作流请使用复制。运行、等待及结果未核对的任务需先停止或核对；原生来源只读。输入框与大编辑框保留原有文本快捷键。
- 任务正文下的回形针支持多文件原生上传、进度、取消、失败重试和移除；刷新恢复已确认附件。每任务最多 100 个附件；上传经插件独立暂存 Session，执行前将持久原生文件对象重新登记到目标分支，并随任务一次提交。通用图片文件按文件附件处理，不声明视觉输入。
- 节点折叠保留用户问题并按内容缩小到紧凑高度，隐藏回答、附件、模型和缩放控件；展开恢复原尺寸，长问题仍可滚动阅读。
- 快捷键还包括 Ctrl+A 全选、Ctrl+D 创建副本、Delete/Backspace 移除、F2 重命名、Ctrl+G 打组、Ctrl+Shift+G 解组、F 适应画布、Shift+F 适应所选、Ctrl+Shift+H 恢复移走任务、? 查看帮助。Delete 同时支持节点正文、标题空白和节点按钮焦点；文本编辑、下拉列表及菜单中保留各自键盘语义。文本编辑时不拦截画布快捷键。
- 长文本正文内滚轮用于阅读，画布空白处滚轮缩放。节点右下角可按住左键拖动缩放，尺寸随布局持久化。右上角依次显示折叠/展开与运行按钮；运行中可以停止，等待中可以取消。只有实际执行中的节点显示沿边框循环移动的白色长光带；减少动画偏好下关闭移动。当前版本真实执行失败时显示粗红色虚线边框。
- 点击运行即授权当前任务版本，无需单独批准。前置任务尚未完成或分支正在执行时，请求进入持久等待队列；前置任务当前版本在本分支完成并持久化后自动推进。不会替用户运行尚未点击的前置任务。等待期间修改任务、前置任务、依赖或策略会撤销旧请求，需要再次点击运行。
- 点击焦点节点下方「Agent 执行过程」查看紧凑动作列表。文件、命令、搜索与工具各占一行，展开后查看输出；命令使用单个 Shell 区域，事件与时间收入「更多信息」。不撑大节点，不展示模型内部思考。
- 已完成且持久化的 Execution 可创建历史分支。每个分支使用独立 Session，共享历史使用同一节点 ID；可查看继承的祖先执行记录。
- 连线形成分叉时，在共同前驱的原生完成边界自动建立独立 Session；历史中间节点新接路径也从该节点边界分支，不带入后续任务。线性后继复用所属路径的会话。自动分支保留当前工作流总览，各节点状态、执行过程和会话信息指向实际路径；也可通过分支选择器查看单一路径。
- 每次开始执行时保存直接前驱的 `inputRunIds`。上游改版或在当前总览重跑后，旧下游输出显示「结果已过期」；后继等待前置任务重跑，不会静默沿用过期结果。显式历史分支仍按自身继承前缀判断；改变下游全局模型不会使已完成上游结果失效。自动重跑切换路径时，执行面板会跟随仍可见的执行记录，保留有效的历史选择。

自动保存节点、尺寸、连线、分组、附件引用、视口和会话根布局。撤销/重做最多保留当前页面每工作流最近 80 次编辑，不回退原生执行历史；与其他窗口的实质编辑冲突时保留数据并提示。失败后保留内存草稿并可重试。焦点和步骤展开仅属于 UI 状态。等待「已保存」再关闭；强制关闭可能丢失尚未提交的修改。

## 原生集成与边界

首次执行会新建 Session 或在来源的原生 completed turn/end 边界 Fork。每个排队请求在实际开始前重新解析已持久化的前驱上下文，确认路由后再向原生 Agent 提交；不同分叉、不同根任务及历史中间节点的新路径不会共用混杂上下文。导入、规划和分支操作不向来源 Session 提交消息。显式打开原生聊天后，用户仍可正常使用原生功能。

原生 Fork 只能继承一条事件历史，无法直接合并独立 Session。多父任务若没有一条原生历史同时包含全部前驱，本次执行会在提交前失败并说明原因；请先选择单一路径，或编写明确的汇总任务。既有混杂聊天不自动改写；若前驱历史已经包含兄弟路径内容，需从干净历史分支重新执行前驱。检测到分支原生聊天新增内容时，后继会从干净的前驱边界 Fork；前驱边界本身已被污染时会阻止执行。插件内运行会串行校验和持久化路由；rc.3 未提供跨原生聊天和插件的原子历史版本锁，不应在同一目标 Session 同时手动发消息和运行工作流。工作目录仍由原生 Session 配置决定，Session 隔离不复制或隔离磁盘文件。

规划采用专用 Agent，允许原生 read 工具只读取本次上传的已验证文件，其他文件、命令、写操作和委派仍由正式 tools.guard() 禁止。规划面板支持文件上传、进度、取消、重试、移除和模型切换；模型选择位于发送按钮左侧，宽度随名称调整，输入框随文字增高并在上限后滚动；原生提交确认前保留目标与附件。用户显式提交规划目标在 Manual / Suggest / Dynamic 下均可用；Manual 只禁止自动规划。工作流模型用于规划，确认后仅加入草稿与依赖。原生执行完成且输出合法 JSON 后进入计划审核；接受计划只创建草稿，每个任务通过运行按钮提交。每次执行在授权时固定实际 provider/model，支持同批次不同节点使用不同模型；只作用于对应的 Workflow 请求和分支，不修改原生 DSH 全局默认模型，完成后不会覆盖原生聊天的模型选择。所有执行模式只推进用户已点击运行的队列，保留旧策略枚举用于读取既有数据。失败或未知结果不自动重试。Dynamic 仅在该模式下成功执行后生成待审建议，不自动接受或运行。每个分支串行推进。

启动时核对前后台插件版本与能力。若旧后台仍在运行，界面说明需要完全退出（包括托盘）再启动；恢复连接不会重发此前的运行或删除操作。

Host 持续订阅原生事件，Client 定时刷新投影。工具审批同时显示在轨迹和独立审批浮层中，可直接允许一次或拒绝；冷恢复缺少原生等待 resolver 时只读提示。模型和访问模式来自 DSH 当前注册项，各次运行固定自己的选择。自动集成测试使用受控模型传输；Agent Loop、工具、事件、Fork 和 JSONL 持久化均为真实 rc.3 组件。

Workflow 只保存引用、摘要、计划、审批和操作意图。完整输入输出由 DSH Session Persistence 管理。未知提交结果标为需要核对，重启不会自动重发。两类存储没有跨库事务，不能承诺跨进程故障下的 exactly-once。

## 安装

使用官方 CLI 安装本地包，完成后重启应用：

```powershell
$cli = "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"
& $cli plugin --profile desktop add 'C:\path\dsh-visual-workflow-0.16.3.tgz' --ignore-scripts
```

停用/卸载使用原生插件管理或官方 plugin remove。数据保留在当前 storage root 的 visual_workflow.json；升级时备份 Phase 1 记录并转换为 schemaVersion 2，保留原图。旧版没有固定模型的等待请求在升级后会撤销，需核对当前模型并重新点击 Run。

交付目录 Start-Workflow.cmd / .ps1 是可选独立 Web 入口，使用 workflow-data home，不读取主应用会话。
